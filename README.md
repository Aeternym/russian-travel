# Путешествия по России / Russian Travel

**Адаптивный одностраничный сайт о путешествиях по России**, выполненный как учебный проект по вёрстке в Яндекс Практикуме. Основной акцент — корректное расположение контента на экранах разной ширины.

> **English:** Responsive travel-themed landing page built with HTML, CSS Grid, Flexbox, media queries, and the BEM methodology.

**[Открыть опубликованный сайт](https://aeternym.github.io/russian-travel/)**

## Что реализовано

- Адаптивная сетка для текстовых блоков, фотографий и карточек направлений.
- Сочетание **CSS Grid** и **Flexbox** для разных типов секций.
- Медиазапросы для изменения компоновки на разных разрешениях.
- Организация CSS по методологии **БЭМ / Nested**.
- Локальное подключение шрифтов Inter, работа с изображениями и относительными путями.

## Стек

`HTML5` · `CSS3` · `CSS Grid` · `Flexbox` · `Media Queries` · `BEM Nested`

## Структура

- `index.html` — основная разметка.
- `blocks/` — стили блоков и элементов по БЭМ.
- `pages/index.css` — точка подключения стилей.
- `images/`, `fonts/`, `vendor/` — ресурсы и общие стили.

## Как запустить локально

Склонируйте репозиторий и откройте `index.html` в браузере. Для просмотра не требуются Node.js или сервер.

## Чему посвящена учебная работа

В рамках проекта отрабатывались адаптивная вёрстка по макету, медиазапросы, сетки CSS и поддерживаемая структура стилей.

**Программа:** [Яндекс Практикум — «Веб-разработчик»](https://practicum.yandex.ru/web/).

*Проект учебный; ссылки переключения языка в макете не означают наличие полноценной локализации.*
